# دليل مدير المنصة

لمديري المنصة فقط. «لوحة المنصة» (`platform.html`) تدير المؤسسات المستأجرة وباقاتها، ولا تعرض أي بيانات تشغيلية للمؤسسات. عودة إلى [فهرس الأدلة](index.md).

> حساب مدير المنصة يُضاف من SQL Editor في Supabase فقط (جدول `platform_admins`)، ولا يُمنح من أي شاشة.

## كيف أنشئ مؤسسة جديدة؟

1. «إنشاء مؤسسة جديدة»: «الاسم بالعربية» و«الاسم بالإنجليزية» و«المعرّف المختصر (slug)» (حروف إنجليزية صغيرة وأرقام وشرطة، 2–40) و«بادئة الأرقام المرجعية» (2–5 حروف إنجليزية كبيرة) و«اللغة الافتراضية».
2. «الفرع الأول»: «رمز الفرع» واسمه والمدينة.
3. «مدير المؤسسة»: البريد الإلكتروني. تُنشأ له دعوة بصلاحية «مدير المؤسسة».
4. «إنشاء المؤسسة». يظهر «رابط الدعوة» **مرة واحدة فقط**: انسخه وأرسله إلى مدير المؤسسة بطريقة آمنة.
5. إن ضاع الرابط: «إعادة إصدار دعوة المدير» في صف المؤسسة (يُبطل الرابط السابق).

مثال: مؤسسة «مؤسسة تجريبية ب» بالمعرّف `org-g7b` والبادئة `TSB`؛ مراجعها تبدأ `TSB-` ومستقلة تمامًا عن مراجع المؤسسات الأخرى.

> كل مؤسسة جديدة تأخذ تلقائيًا باقة «تجريبية» (`pilot`) بلا حدود وبحالة «نشط».

## كيف أدير الباقات؟

بطاقة «الباقات»: جدول بالرمز والاسم والحدود الستة والسعر وعدد المؤسسات وحالة التفعيل.

1. «باقة جديدة» أو «تعديل» يفتح نموذجًا فيه: «رمز الباقة»، الاسم بالعربية والإنجليزية، «ترتيب العرض»، «الباقة مفعّلة»، «حدود الباقة» الستة، «السعر الشهري (ر.س، اختياري)»، و«ملاحظات».
2. الحقل الفارغ = «غير محدود». «التخزين (غيغابايت)» يُدخل بالغيغابايت ويُحفظ بالميغابايت.
3. رمز الباقة لا يتغير بعد إنشائها. باقة `pilot` لا يمكن إيقافها.

| الحد | ماذا يقيس |
|---|---|
| المستخدمون | المستخدمون الذين لهم دور موظف نشط (العملاء لا يُحتسبون، والدور الثاني للمستخدم نفسه لا يُحتسب مرتين) |
| الفروع | الفروع النشطة |
| المعاملات / شهر | المعاملات المنشأة في الشهر (بتوقيت الرياض) |
| التخزين | حجم المستندات ومستندات المالية ومرفقات الرسائل (تراكمي) |
| الرسائل / شهر | كل الرسائل الواردة والصادرة؛ **يُمنع الإرسال فقط**، والوارد لا يُرفض أبدًا |
| المعالجة الآلية / شهر | تشغيلات التحليل الآلي؛ **يُمنع طلب المسودة فقط**، ومعالجة الوارد لا تتوقف |

> القيم الأولية لباقتي `basic` و`pro` قيم مبدئية — قرار المالك. الأسعار فارغة («لم يُسعَّر») حتى يقرر المالك بعد نموذج التكلفة والاستخدام الفعلي.

## كيف أغيّر باقة مؤسسة؟

بطاقة «الاشتراكات والاستخدام»: لكل مؤسسة الباقة والحالة والفترة وخلايا «المستخدم / الحد»، وتظهر الخلية بلون تحذير عند التجاوز.

1. «تغيير الباقة»: اختر الباقة، والحالة («تجريبي» بتاريخ نهاية، أو «نشط»)، وبداية الفترة ونهايتها، وتجاوزات الحدود لهذه المؤسسة إن لزم، و**السبب (إلزامي)**.
2. التخفيض تحت الاستخدام الحالي مسموح: لا يُحذف شيء ولا يُعطَّل، فقط تُرفض السجلات الجديدة من النوع المتجاوز، وتظهر الحدود المتجاوزة.
3. «الاستخدام»: «الشهر الحالي» و«آخر الأشهر» و«آخر أحداث الاشتراك».
4. «إعادة احتساب»: يعيد حساب العدادات من السجلات الفعلية (آمن للتكرار).

> بلاطة «تجاوز حدود الباقة» تعرض عدد المؤسسات التي تجاوزت حدًا واحدًا على الأقل.

## كيف أوقف مؤسسة أو أعيد تفعيلها؟

1. «تعليق» في «الاشتراكات والاستخدام» (أو «إيقاف» في جدول «المؤسسات»): اكتب «السبب» (**إلزامي**). خيار «إلغاء الاشتراك (بدلًا من التعليق)» يجعل الحالة «ملغى» بدل «موقوف».
2. أثر الإيقاف فوري: لا وصول لموظفي المؤسسة، ولا لبوابة العميل، ولا للتتبع العام، وتتوقف نماذجها العامة. **لا تُحذف أي بيانات.**
3. «إعادة تفعيل» بسبب إلزامي تعيد الوصول فورًا لأعضائها المفعّلين.

| حالة الاشتراك | ماذا يعني |
|---|---|
| تجريبي | يعمل حتى تاريخ نهاية الفترة؛ بعدها اطلاع وتعديل فقط، ولا سجلات جديدة حتى التمديد أو التحويل إلى «نشط» |
| نشط | يعمل ضمن حدود الباقة |
| موقوف | لا وصول (إيقاف كامل)، والبيانات محفوظة |
| ملغى | مثل الموقوف |

> كل تغيير في الباقة أو الحالة يُسجَّل في أحداث الاشتراك (للإضافة فقط) وفي سجل التدقيق.

## كيف أتابع صحة الخادم والأخطاء؟

- «صحة الخادم» ← «فحص الآن»: الحالة، وقت قاعدة البيانات، «إصدار المخطط» (آخر ترحيل مطبّق)، البيئة، زمن الاستجابة.
- «أخطاء الواجهة الأخيرة»: أخطاء JavaScript من متصفحات المستخدمين في كل المؤسسات بعد حذف البيانات الشخصية.

## ماذا أرى وماذا لا أرى؟

ترى: المؤسسات، وأعداد الفروع والأعضاء، والباقات، والاشتراكات، وأعداد الاستخدام فقط. لا ترى: معاملات المؤسسات أو عملاءها أو مراجعها أو مبالغها أو رسائلها. مدير المنصة ليس عضوًا في أي مؤسسة.

## ما لا يفعله النظام

- لا يفوتر الاشتراكات ولا يحصّل دفعًا إلكترونيًا (مؤجل إلى ما قبل البيع).
- لا يحذف مؤسسة ولا بياناتها؛ الإيقاف والإلغاء يحفظان كل شيء.
- لا يرسل رابط دعوة المدير بالبريد؛ تنسخه وترسله بنفسك.
- الواجهة لا تقرر الحدود؛ الخادم يرفض السجل المتجاوز برسالة «وصلت المؤسسة إلى حد الباقة».
