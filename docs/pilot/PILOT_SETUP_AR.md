## 2) مطلوب من المالك قبل يوم البدء

1. **قائمة المشاركين** في [`participants.csv`](participants.csv): الاسم، بريد شخصي يملكه المشارك (لا حسابات مشتركة)، الدور، الفرع. يمكن أن يكون المالك نفسه «مدير المؤسسة».
2. **كلمة مرور حماية الموقع (Hostinger Basic Auth)**: يرسلها المالك لكل مشارك بنفسه، منفصلة عن رابط الدعوة.
3. **قرار النسخ الاحتياطي** (أحدهما):
   - تشغيل `scripts/backup-staging.sh` يدويًا قبل البدء وأسبوعيًا (يحتاج تثبيت `pg_dump`، ورابط اتصال القاعدة يُدخله المالك بنفسه — لا يُرسل في المحادثة)؛ أو
   - الترقية إلى خطة Supabase المدفوعة (نسخ يومية).
   البيانات تدريبية، فالخطر محدود، لكن فقدانها يضيع ملاحظات التجربة.
4. **تاريخ البدء والمدة** (المقترح 4 أسابيع) وجلسة التدريب الأولى.
5. **مزوّد البريد**: تجربة بريد Hostinger المجانية تنتهي 2026-12-03 والتجديد التلقائي مفعّل — قرار قبل ذلك التاريخ.

## 3) بعد استلام القائمة (ينفذها المطوّر)

1. إنشاء الدعوات من «الأعضاء والدعوات» لكل مشارك بدوره وفرعه، وتسليم الروابط للمالك ليرسلها بنفسه (البريد الآلي للدعوات غير مفعّل بعد؛ صلاحية الرابط 7 أيام).
2. للمشارك بدور «عميل»: إنشاء ملف عميل تدريبي ثم دعوته مربوطًا به.
3. التحقق بعد قبول كل دعوة: الدور والفرع الصحيحان، وأن موظف فرع لا يرى معاملات الفرع الآخر.
4. تسجيل الحالة هنا (جدول §5).
